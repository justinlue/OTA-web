# OTA Web UI — implementation plan

Spec: `docs/superpowers/specs/2026-10-25-ota-webui-design.md`.

1. Scaffold: Vite + React + TS, Vitest (jsdom), repo docs, timeline.
2. `src/protocol/`: types, topic builders/parsers, payload validation, error table. Tests first.
3. `src/core/`: version compare, eligibility, effective job state + watchdog,
   dispatcher, lease, batch summary — pure functions. Tests first.
4. `src/transport/`: `Transport` interface, in-memory broker + client, `mqtt.js` adapter.
5. `src/sim/`: simulated devices on the in-memory broker. Tests with fake timers.
6. `src/engine/`: `OtaEngine` — vanilla Zustand store fed by the transport;
   tick loop (dispatch, heartbeat, toasts); actions (start batch, retry,
   cancel, archive, delete, take over, catalog CRUD). Integration tests on the
   in-memory broker.
7. `src/ui/`: shell + hash routing, Devices (virtualized table, filters, paste
   selection, Start dialog), failure drawer, Batches + detail, Firmware,
   Settings. Light component tests.
8. `docs/protocol.md`, README, CLAUDE.md; build, typecheck, test; record
   timeline nodes.
